# Создание веб-приложения библиотеки игр с помощью .NET с использованием подхода MinimalAPI, технологии Blazor для отрисовки интерфейса, наличием базы-данных.

## За референс для конечного продукта был выбран сайт LiveLib

## На данный момент приложение может только отправлять GET и POST запросы для получения всей сохраненной библиотеки игр, регистрации пользователя, входа в систему. В дальнейшем планируется реализовать:

### Добавление пользовательских тэгов для игр

### Добавление профиля пользователя с возможностью добавлять описание профиля и ставить аватарку, создание личного списка продуктов по категориям

### Добавление пользовательской активности в виде выставления рейтингов и написания обзоров

### Добавление изображений к играм

### Добавление ролей обычных пользователей и модераторов. Добавление модерации добавляемых в базу игр

### Добавление проверки вводимых значений с помощью регулярных выражений

### Добавление полноценной регистрации по имэйлу (с отправкой кода и т. п.)

### Расширение и улучшение пользовательского интерфейса
